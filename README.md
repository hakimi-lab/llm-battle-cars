# LLM Battle-Cars Arena (v4.0 — 大模型 AI 造车对抗赛 · 360° 独立旋转炮塔、纯手写控制律与三大主题地形擂台)

欢迎来到 **LLM Battle-Cars Arena** —— 一个面向大语言模型与 AI Agent 的 **3D 模块化物理造车 + 纯手写差速与炮塔控制策略 + 三大零重复主题地形擂台 BO3 对抗赛 + 战车外形展示** 评测平台。

每位参赛 AI **只需编写并交付唯一一个 `.json` 文件**（无需修改平台代码、无需额外脚本或环境配置），即可同时定义：
1. **自由尺寸的 3D 物理战车结构与近战/远程武器组装**（**不限制战车长宽高上限**！共 13 种功能零件，含 **360° 独立旋转云台远程能量炮 `energy_cannon`**、旋转/气动近战武器、实体护甲与多档齿轮驱动轮；真实物理体积×密度决定重量、速度与抗掀翻能力）
2. **自定义配色与 3D 几何外观件**（`decorations` 消耗 `0` 建造点数、零碰撞体积，用于 **战车外形评价环节**，风格与主题完全由模型自由决定，不做任何预设导向）
3. **100% 由模型自主编写的底层差速轮、360° 炮塔与武器控制策略**（**无任何预设自动驾驶或自动瞄准指令**！平台不提供 `pursue` / `dodge` / `auto_aim` 等现成宏；参赛模型需直接根据 **68 维原始物理坐标、速度、炮塔方位与泥地/冰面/弹射板地形传感器**，自主用数学公式/状态变量与条件规则写出左右轮电机输出 `left` / `right`、能量炮云台旋转角 `cannon_yaw_deg` / `cannon_turn` 与武器开火时机——如何转向、如何边横向走位边独立转炮塔预判射击、如何沿干爽石板路绕过粘稠泥沼或把对手推进泥潭/镜面冰道滑落悬崖，全靠模型自己的几何与物理推理！）

## 1. 快速上手 (Quickstart)

```bash
# 1. 克隆仓库并安装依赖 (支持 Linux / macOS / Windows / 无显卡云端沙盒)
git clone https://github.com/hakimi-lab/llm-battle-cars.git
cd llm-battle-cars
pip install -r requirements.txt

# 2. 查看全部 13 种功能零件、装饰几何体与 3 张 BO3 战术机关场地 (0 模拟额度)
python arena.py parts

# 3. 校验战车 JSON 语法、策略数学表达式编译、整车重量分级与平地实测极速诊断 (0 模拟额度)
python arena.py validate examples/starter_template.json

# 4. 生成战车四视图或场地 3D 结构蓝图 PNG (0 模拟额度)
python arena.py preview examples/starter_template.json
python arena.py preview-arena --stage all

# 5. 与内置陪练车或【你自己设计的假想敌战车】进行 360Hz 物理实战测试！
#    (消耗模拟额度：单图 1 点，BO3 消耗 3 点，总硬性上限 120 点)
python arena.py test examples/starter_template.json --opponent dummy_ranger --stage bo3
python arena.py test submissions/my_car.json --opponent custom_opponents/my_test_foe.json --stage bo3
```

> **完整字段、零件参数、原始传感器与纯数学控制策略语法手册请阅读：[SPECIFICATION.md](SPECIFICATION.md)**

## 2. 核心比赛规则与物理平衡机制 (Tournament Rules & Physics Balance)

1. **单文件交付**：每位参赛 AI 最终只需在 `submissions/` 下输出并交付**唯一一个正式参赛 JSON 文件**（如 `submissions/<你的模型名>.json`）。
2. **零预设自动驾驶/自瞄宏 —— 100% 由模型手写底层控制律 (`strategy`)**：
   - 平台**没有**任何预制的移动或自动瞄准模式（不存在 `"drive": "pursue"` 或现成的闪避/自瞄宏）。
   - 模型在 JSON 的 `"strategy"` 中通过状态变量 (`vars`)、中间数学公式 (`let`，上限 `36` 个) 和优先级规则 (`rules`)，直接输出左右驱动轮电机油门 `"left"` / `"right"` (`-1.0 ~ +1.0`)、可选 360° 能量炮云台转角 `"cannon_yaw_deg"`（或角速度 `"cannon_turn"`）与各武器开关。无论是车体横切走位同时炮塔独立锁敌预判射击、侧闪躲避飞来的能量弹、翻车反向补偿，还是沿石板路绕过泥沼、把对手推进弹射板/泥潭/镜面冰道滑下悬崖，均完全考验模型自身的几何建模与控制设计能力！
3. **单局 `30` 秒时长与百点裁判实时计分**：
   - 每小局最长 **`30.0` 秒**；将对手击落悬崖 (`z < -0.45m`) 直接判 **KO 获胜**，对手翻车瘫痪 (`tilt_deg > 92°` 且 `speed < 0.12 m/s`) 连续满 **`4.0` 秒** 直接判 **TKO 获胜**。
   - 若 `30` 秒打满双方均存活，按实时计算的 **100 分制裁判总分** 判胜：**有效杀伤分 `0–50` 分**（双方按累计碰撞/武器/炮击冲量、掀翻次数与弹射板诱导次数占比瓜分）+ **压制与内圈控场分 `0–30` 分**（双方按主动逼近与占据内圈优势占比瓜分）+ **车身姿态稳定分 `0–20` 分**（各自按平稳行驶帧占比独立计分）。
4. **不限制战车长宽高上限 + 重量与速度真实平衡**：
   - 平台**不设整车长、宽、高外包围盒上限**（仅要求底盘最小厚度 `>= 0.06m`），3D 体积 × 密度自然决定整车质量 `M` 与转动惯量 `I`。
   - 全车共享车载电机功率池并计算真实接地滚阻（`validate` 会直接返回你的实测 `total_mass_kg` 与 `est_top_speed_mps`）：
     - **轻量级 (`< 28 kg`，搭配 `speed` 齿)**：极速高（约 `4.0–4.5 m/s`）、掉头极快，适合写灵活走位躲炮弹、绕后突袭，但抗击退与抗掀翻能力较弱。
     - **中量级 (`28–44 kg`，搭配 `balanced` 齿)**：速度（约 `3.0–3.5 m/s`）、推力与稳定性兼备。
     - **重量级 (`44–66 kg`，搭配 `torque` 齿)**：重心稳、极难被掀翻或击退，正面顶推强悍，但极速（约 `2.1–2.6 m/s`）与转向明显变慢（强装 `speed` 齿会因过载带不动而更慢）。
     - **超重型 (`>= 66 kg`)**：稳如磐石但机动迟缓（`< 1.9 m/s`）。
5. **功能零件与点数上限（无能量盾，鼓励进攻与走位）**：
   - 功能零件数量（`parts`）：**最多 `14` 个**（最少 `1` 个）；总建造点数：**`<= 100` 点**。
   - 主动动力武器数量：**最多 `4` 个**（其中 `energy_cannon` 最多 **`2` 门**，自带 `360°` 独立电控旋转云台）。实体防御件 `armor_shield` 与 `wedge` 使击中该部位的 `energy_cannon` 炮弹伤害与击退衰减 **`30%`**。
6. **战车外形评价环节（`decorations` 免费额度，风格完全自由）**：
   - 允许添加**最多 `10` 个 `decorations` 几何外观件**（`0` 点数、零碰撞、不限尺寸），用于独立的 **360° 展台「战车外形评价环节」**，外观主题与风格完全由模型自主决定。
7. **支持自建「假想敌」(`custom_opponents/`) + 白盒策略体检 + `120` 点模拟额度硬上限**：
   - `validate` / `preview` / `preview-arena` 消耗 **`0` 点额度**（`validate` 会静态编译并试运行你的所有数学公式，直接报出语法或变量名错误！）。
   - 单图测试消耗 **`1` 点**，`--stage bo3` 消耗 **`3` 点**，总硬性上限 **`120` 点额度**（最多可跑 `40` 轮完整 BO3 或 `120` 局单图精细调参）；每次 `test` 自动返回白盒 `strategy_diagnostics_A`（含泥地/冰面停留时长与炮塔累计转角）、每秒轮速/炮塔角/坐标黑匣子时间轴及 **2D 战术轨迹复盘图 (`tactical_trace_png`)**。

三张 BO3 场地拥有截然不同的 3D 沙盘视觉美术风格与**每局必触发的地形/机关物理**（**零立柱障碍、零窄桥卡点、零机制重复**；所有弹射板、泥沼与镜面溜冰带坐标/距离/状态均实时暴露在 **68 维原始物理传感器**中供模型设计战术！）：

| 局数 | 场地代号 | 场地名称 | 地形美术与专属可利用物理机制 |
| :--- | :--- | :--- | :--- |
| **Game 1** | `spring_arena` (`1`) | **霓虹四象·赛博弹射台** | 直径 `6.9m` 暗钛青霓虹圆台；内圈 `r=2.45m` 平地 + 外圈无缝 **`-7.5°` 危险溜坡悬崖边**；四角 `(±1.18, ±1.18)` 嵌有 **4 块琥珀橙边缘灵敏铰链斜向弹射板**（外侧边固定地面，车轮或前铲压上边缘瞬间撑起 `56°` 朝四角斜向击飞，回落零碰撞不夹车！） |
| **Game 2** | `mud_arena` (`2`) | **翡翠湿地·泥沼陷车台** | `7.2m × 5.8m` 翡翠玄武岩高原（南北两侧 `-7.0°` 苔藓溜坡悬崖 + 暖黄砂岩石板干路绕行道 `y≈±1.50m`）；分布 **3 片粘稠泥炭沼泽**（正中大泥潭 `(0,0)` 直接横亘在无脑直线对冲路线上 + 西北 `(-1.78,+1.50)` / 东南 `(+1.78,-1.50)` 角池）。**所有战车涉入泥潭一视同仁减速约 `50%`（零静摩擦不死卡）**，走干爽石板路包抄或把对手推/轰进泥潭当靶子打收益极高！ |
| **Game 3** | `ice_ridge` (`3`) | **极地冰川·溜冰飞坡台** | `7.4m × 5.8m` 极地冰川擂台；正中横贯高抓地力 **`+0.26m` 冰川飞坡天桥**（`14.2°` 斜坡阻断平射视线、可腾空飞跃），外围四边（`|x|>=2.12m` 或 `|y|>=2.08m`）环绕**超低摩擦镜面溜冰带（轮胎抓地力骤降至 `μ=0.10`，刹车滑行距离放大约 `10` 倍！）**并直通东西两侧 **`-8.0°` 冰滑梯悬崖边**——把对手撞上或轰上镜面冰带就会失控打滑坠入冰渊！ |

## 4. 13 种功能零件速览 (`parts`, 上限 14 件 / 100 点)

| 零件 `type` | 点数 | 类别 | 功能与物理机制 |
| :--- | :---: | :---: | :--- |
| `frame` | **4** | 结构 | 扩展结构梁（不限最大长宽高），可向外延伸车体并作为其他零件的父节点 (`parent`) |
| `wheel` | **6** | 机动 | 橡胶驱动轮（支持 `speed` / `balanced` / `torque` 齿轮比或 `free` 从动轮） |
| `monster_wheel` | **10** | 机动 | 大尺寸宽胎驱动轮；轮径超出车体上下表面时支持翻车后倒置行驶（注意翻车时需自己在策略里翻转左右轮符号！） |
| `wedge` | **7** | 控制 | 低摩擦精钢斜铲，铲起对手底盘破坏抓地力，并衰减 `30%` 命中的能量炮弹冲量 |
| `armor_shield` | **6** | 防御 | 实体防爆装甲板，抵御近战旋转武器，并衰减 `30%` 命中的能量炮弹伤害与击退 |
| `gyro_stabilizer` | **7** | 防御 | 高密度底盘配重圆盘，降低重心以抗掀翻（会显著增加车重、降低极速） |
| `spinner_horiz` | **18** | 武器 | 水平高速旋转刀梁，造成大范围横向碰撞冲量 |
| `spinner_vert` | **20** | 武器 | 垂直上勾滚筒，贴身命中时向上挑飞对手 |
| `flipper` | **16** | 武器 | 气动弹射铲（冷却 `1.3s`），瞬间向上掀起 `72°` 抛飞对手或翻车自救 |
| `hammer` | **15** | 武器 | 过顶动力战锤（冷却 `1.15s`），向下猛砸 `115°` 打击敌方顶部或翻车自救 |
| `piston_punch` | **15** | 武器 | 直线伸缩冲拳（冷却 `1.1s`），近距离瞬间向前猛推 |
| `energy_cannon` | **18** | 武器 | **360° 独立旋转云台**远程电磁/等离子能量炮（限装 `2` 门，`rapid` / `standard` / `heavy` 三档，最大转速约 `343°/s`）：支持在 `strategy` 中用 `"cannon_yaw_deg"` 或 `"cannon_turn"` 边横向走位边独立转炮塔预判射击，带斜向上挑冲击波，点杀陷泥对手或将敌人轰上冰面滑落悬崖极强！ |
| `thruster` | **14** | 武器 | `95N` 推进喷射器（`1.8s` 自动充能燃料槽），提供爆发冲刺、脱泥、冰面救车或飞坡推力 |

详细 JSON Schema、参数范围、单局 `30` 秒判胜计分规则、68 维原始传感器与数学公式函数表请查阅 **[SPECIFICATION.md](SPECIFICATION.md)**。
